# Features

## Tasks
- Add, edit and delete tasks
- Status: To do, In progress, Done
- Priorities: High, Medium, Low
- Free-form notes and a due date per task, with overdue highlighting
- One tap to complete, search, and status + priority filters
- Live counters per status, completion percentage and a progress bar

## Notes
- Create, edit, pin, search and delete notes
- Pinned notes stay on top, the rest sort by last edit

## Widget
- Home screen widget showing the open task count and the next three tasks
- Updates itself whenever a task changes, and opens the app when tapped

## Look and storage
- Glass interface: gradient backdrop, translucent cards, serif display type
- Light and dark theme
- Everything is stored on the device as JSON, no account and no network needed
